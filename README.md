# FitBite - Nutrition Tracker

FitBite is a Java Swing desktop application that helps
users track their daily food intake and nutritional values.

## Features

- Track daily calories
- Monitor protein, carbohydrates, and fats
- Add and delete food entries
- View daily nutrition totals
- Navigate between dates
- Save nutrition records locally

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming
- ArrayList
- File Handling

## How to Run

1. Install JDK 21 or a compatible JDK.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Compile the project:

   javac *.java

6. Run the application:

   java Main

Java Desktop Application
